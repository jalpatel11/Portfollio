# Jal Patel — Portfolio

Personal portfolio website built with React and Vite.

## Tech Stack

- **React 19** — UI
- **Vite 7** — Build tooling
- **Custom CSS** — No frameworks, hand-crafted styles
- **Google Fonts** — Bebas Neue, IBM Plex Mono, Playfair Display

## Features

- Custom animated cursor
- Scroll-triggered reveal animations
- Glitch text effect on role switcher
- Animated skill bars
- Marquee ticker
- Responsive layout (mobile-first)
- Grain texture overlay
- Full-screen overlay navigation (mobile)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
